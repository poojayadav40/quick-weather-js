## ✨ Features

* 🌡️ **Real-Time Weather Data:** Fetch current temperature, humidity, wind speed, and weather condition icons.
* 🔍 **City Search:** Easily search for weather conditions in any city worldwide.
* 📱 **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* 🎨 **Modern UI:** Minimalist and clean styling with clear visual cues.

---

## 🛠️ Tech Stack

* 🌐 **HTML5:** Semantic structure and content markup.
* 🎨 **CSS3:** Custom layout, modern styling, and responsive design.
* ⚡ **JavaScript (ES6+):** Asynchronous API integration and DOM manipulation.
* 🌤️ **Weather API:** OpenWeatherMap API *(or your preferred weather API provider)*.

## 🚀 Quick Start

### 📋 Prerequisites
Make sure you have a modern web browser installed (Chrome, Firefox, Edge, Safari).

### 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/poojayadav40/quick-weather-js.git](https://github.com/poojayadav40/quick-weather-js.git)
2. Navigate to the project directory:
   cd quick-weather-js
3. Open the application:
Simply double-click index.html or open it with a live server extension (e.g., Live Server in VS Code).
